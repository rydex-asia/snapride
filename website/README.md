# RYDEX Website

Static website prototype based on the Rydex app flow.

## Run locally

Option 1:
- Open `index.html` directly in a browser.

Option 2 (recommended):
- From `website` folder, run:
  - `python3 -m http.server 8080`
- Open `http://localhost:8080`.

## Included behavior

- Suggestions/services cards with real image assets.
- Banner slider.
- Booking form with:
  - Use current location
  - Add stop / remove stop (`-`)
  - Continue button opening Google Maps directions with waypoints.
- Profile section with editable details.
